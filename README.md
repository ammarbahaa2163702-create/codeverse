## 🚀 المميزات الرئيسية (Core Features)

1. **منهج تعليمي تفاعلي متكامل:**
   - دروس متدرجة تغطي HTML الدلالي، تقنيات Flexbox و Grid، النماذج المتقدمة، وحركات CSS، وجافاسكريبت التفاعلية.
   - تحديات برمجية مع مدقق ذكي ومصحح أخطاء يترجم الأخطاء البرمجية إلى نصائح عربية واضحة.
2. **محرر كود احترافي (CodeMirror 6):**
   - تلوين برمجي فوري لـ HTML / CSS / JS مع مسافات تلقائية وترقيم أسطر حقيقي ودعم الوضعين الفاتح والداكن.
3. **مختبر المحاكاة والأكواد الجاهزة (Showcase Lab - 10 Demos):**
   - **ملعب الشيدر التفاعلي (WebGL Plasma):** شيدر بكسلات ومعادلات Domain Warping نقية.
   - **سرب الطيور الذكي (Boids Flocking AI):** خوارزمية Craig Reynolds لسلوك الكائنات والأسراب.
   - **مستكشف الكسيريات (Mandelbrot & Julia):** تكبير سلس وتلوين لوغاريتمي ودعم حركات اللمس.
   - **محاكي مدارات المجموعة الشمسية (Solar System):** محاكاة سرعات كبلر المدارية بـ Canvas 2D.
   - **محاكاة قماش الحرير (Verlet Cloth Physics):** فيزياء القيود وتكامل Verlet مع تمزيق الخيوط بالسحب.
   - **محرك 3D النقي (Canvas 3D Wireframe Engine):** رياضيات الفضاء الثلاثي ومصفوفات الدوران والتحول الشكلي.
   - **آلة الموسيقى ومرئي الطيف (Web Audio Synth):** سنثسايزر صوتي حقيقي ومرئي طيف ترددي دائري بـ AnalyserNode.
   - **الفيزياء الطباعية التفاعلية (Typographic Physics):** تحليل بكسلات النصوص وتشتيتها بالنوابض التفاعلية.
   - **بطاقات 3D الهولوجرامية (Holographic Perspective):** منظور ثلاثي الأبعاد وانعكاس إضاءة بـ CSS 3D.
   - **شبكة الجسيمات المترابطة (Particle Constellation):** مصفوفة المسافات والموجات الصدمية.
4. **نظام التقدم والأوسمة (Gamified Mastery):**
   - احتساب نقاط الخبرة (XP)، تسجيل أيام المواظبة، شارات استحقاق متدرجة، وحفظ محلي آمن بالإصدارات (`schemaVersion: 2`).
5. **هوية بصرية معتمدة وإمكانية وصول (Accessibility):**
   - ثيم داكن وفاتح حقيقي مع حفظ التفضيل.
   - متوافق مع معايير WCAG AA ودعم `prefers-reduced-motion`.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** React 19, Vite 8
- **Styling:** Tailwind CSS 3.4, Vanilla CSS Design Tokens
- **Editor:** CodeMirror 6 (`@uiw/react-codemirror`)
- **Icons:** Lucide React
- **Audio & Visuals:** Web Audio API, WebGL, Canvas 2D

## 💻 التشغيل المحلي (Getting Started)

### المتطلبات الأساسية
- Node.js (الإصدار 18 أو أحدث)
- npm أو pnpm أو yarn

### خطوات التثبيت والتشغيل

1. **استنساخ المستودع (Clone the repository):**
   ```bash
   git clone https://github.com/ammarbahaa2163702-create/codeverse.git
   cd codeverse
   ```

2. **تثبيت الاعتماديات (Install dependencies):**
   ```bash
   npm install
   ```

3. **تشغيل خادم التطوير (Run dev server):**
   ```bash
   npm run dev
   ```
   افتح المتصفح على: `http://localhost:5173`

4. **بناء الإنتاج والتحقق (Lint & Build):**
   ```bash
   npm run lint
   npm run build
   ```
